# Premium Light Blue Reference

Use this reference when the user wants a premium, quiet, BMW-adjacent digital deck with cool blue-gray accents and high visual restraint.

## Source

- Local reference file:

## Core Feel

- light premium surfaces
- cool blue-gray palette
- open, digital, precise
- less theatrical than the dark technical style
- more premium product communication than manifesto

## Visual Language

- pale silver-blue or off-white background
- very subtle radial or linear gradients
- crisp borders and soft shadows
- clean rounded panels
- restrained accent color, typically a BMW-like blue
- minimal use of decorative forms

## Typography

- modern sans with strong clarity
- large headlines, but calmer than OEH dark style
- more whitespace between blocks
- monospace only for technical inserts or small metadata

## Layout Rules

- generous outer margins
- strong large-card composition
- avoid overstuffing slides
- keep hierarchy obvious through scale, spacing, and contrast
- use 2-column or 4-card systems with disciplined rhythm

## Copy Style

- still structured and assertive, but calmer
- less "manifesto", more "clear technical explanation"
- headlines should be clean and high-confidence
- supporting text should feel engineered, not dramatic

## Components Worth Reusing

- frosted or light translucent card
- subtle progress / footer chrome
- blue accent dot or rule
- premium terminal module for code or system snippets
- clean source callout blocks

## Failure Modes

- too much neutral gray makes the deck feel generic
- too much blue turns it into enterprise SaaS
- if every panel is glassy, the design loses discipline
- premium visual language still needs a real structural story

## Good Use Cases

- product strategy
- technical concept intros
- cross-functional design reviews
- polished internal innovation decks
