## Core Feel

- dark background
- strong contrast
- technical seriousness
- architectural storytelling
- dense but controlled information layout
- more manifesto than marketing deck

## Narrative Pattern

- start with the systems problem, not the feature list
- move from pain to architecture to decisive advantages to practical workflow
- make product, architecture, and language feel like the same object
- treat each slide as a thesis, not a neutral topic header

## Visual Language

- charcoal or near-black background with restrained grid or panel structure
- white or off-white type with cool accent colors
- terminal-like microcopy and monospace labels
- layer notation, tags, state chips, section codes, and structural dividers
- modular cards instead of decorative freeform blobs
- diagrams, comparison tables, layered stacks, and workflow strips

## Typography

- large assertive headline
- tight letter spacing
- short lines with high authority
- monospace only for labels, states, commands, or system markers
- body copy still readable, but not too airy

## Layout Rules

- one dominant thesis per slide
- one supporting structure: grid, stack, flow, or comparison
- use asymmetry, but keep alignment disciplined
- information can be dense if containers and reading order are obvious
- avoid full-width undifferentiated bullet dumps

## Copy Style

- use sharp contrasts like "not X, but Y"
- prefer claims that sound operational, not promotional
- use short anchor lines that can stand on their own
- cut filler, qualifiers, and generic value-prop phrasing

## Components Worth Reusing

- eyebrow / system label
- dark terminal panel
- capability stack cards
- flow arrows
- source grounding block
- state badges like `planned`, `shipped`, `local`, `cloud`

## Failure Modes

- too much density without structure becomes unreadable
- fake technicality looks embarrassing fast
- terminal aesthetics without real system logic become cosplay
- every slide cannot be maximal intensity; add rhythm

## Good Use Cases

- agent systems
- developer tools
- knowledge systems
- architecture narratives
- internal technical strategy decks
